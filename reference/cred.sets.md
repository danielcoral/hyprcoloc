# Credible sets

`cred.sets` computes credible sets of SNPs for each cluster of
colocalized traits

## Usage

``` r
cred.sets(res, value = 0.95)
```

## Arguments

- res:

  list of results from hyprcoloc when setting "snpscores = TRUE"

- value:

  the sum of the probabilities of the snps included in the credible set
